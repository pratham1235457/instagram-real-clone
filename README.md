# Instagram Real Clone

A full-stack Instagram clone featuring user authentication, real-time feeds, photo/video uploads, stories, likes, comments, and direct messaging.

## Features

- **User Authentication:** Secure registration, login, and session management (JWT / OAuth).
- **Dynamic Feed:** Real-time home feed displaying posts from followed users with chronological and algorithmic sorting.
- **Media Uploads:** Seamless photo and video uploads with cloud storage integration and preview support.
- **Stories:** 24-hour disappearing photo/video stories with viewer tracking.
- **Social Interactions:** Real-time likes, nested comments, post saving/bookmarking, and user follow/unfollow functionality.
- **Direct Messaging (DM):** One-on-one real-time chat with read receipts and media sharing.
- **Explore & Search:** Discover new users and trending posts via search and explore grids.
- **User Profiles:** Customizable profiles displaying bio, profile picture, follower/following counts, and post grids.
- **Responsive Design:** Fully responsive UI tailored for mobile, tablet, and desktop viewports.
